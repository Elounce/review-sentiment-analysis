# Разработка веб-сайта для классификации эмоциональной окраски отзывов на основе наивного байесовского классификатора

Тема работы: **«Разработка веб-сайта для классификации эмоциональной окраски отзывов на основе наивного байесовского классификатора»**

Проект представляет собой веб-приложение для автоматической классификации тональности русскоязычных отзывов. В качестве классификатора используется алгоритм Complement Naive Bayes (`ComplementNB`) из библиотеки Scikit-Learn, а пользовательский интерфейс реализован на фреймворке Streamlit. Система поддерживает пакетную обработку файлов, интерпретацию предсказаний (выделение ключевых слов-триггеров) и цикл дообучения на основе пользовательских исправлений (Active Learning).

## Основные возможности

- **Классификация на 3 категории:**
  - Позитивный отзыв (`positive`);
  - Нейтральный отзыв (`neutral`);
  - Негативный отзыв (`negative`).
- **Интерпретируемость решений (Explainable AI):**
  - Подсветка ключевых токенов и биграмм, которые внесли наибольший вклад в итоговую оценку модели.
- **Два формата ввода данных:**
  - Ручной ввод одного или нескольких отзывов (построчно);
  - Пакетная загрузка файлов через интерфейс (`.csv` или `.txt`).
- **Аналитический дашборд:**
  - Круговые и столбчатые диаграммы распределения тональности;
  - Сортировка отзывов по колонкам с выводом расчетной уверенности модели.
- **Механизм обратной связи (Active Learning):**
  - Интерактивное исправление ошибок классификации через форму в карточке отзыва;
  - Сохранение правок в `data/feedback.csv`;
  - Кнопка моментального переобучения классификатора в боковом меню без перезапуска сервера.
- **Экспорт результатов:**
  - Скачивание размеченного датасета в формате CSV (`utf-8-sig` для корректного открытия в Excel).

## Стек технологий

- **Язык программирования:** Python 3.12 (поддерживается 3.10+)
- **Машинное обучение и NLP:**
  - `scikit-learn` — векторизация текста (`TfidfVectorizer`), классификатор `ComplementNB`, метрики качества, кросс-валидация;
  - `pymorphy3` — морфологический разбор и приведение слов к нормальной форме (лемматизация);
  - `pandas` — манипуляции с табличными датасетами;
  - `joblib` — сериализация и загрузка обученных моделей.
- **Интерфейс и визуализация:**
  - `streamlit` — реактивный веб-интерфейс дашборда;
  - `matplotlib` — построение круговых и столбчатых диаграмм.

## Установка и запуск

### 1. Подготовка виртуального окружения

Рекомендуется изолировать зависимости проекта через виртуальное окружение:

```powershell
# Создание окружения
python -m venv .venv

# Активация в Windows PowerShell
.\.venv\Scripts\Activate.ps1

# Установка библиотек
pip install -r requirements.txt
```

### 2. Обучение модели

Перед первым запуском или после накопления новых правок в `data/feedback.csv` запустите обучение:

```powershell
.\.venv\Scripts\python.exe src/train.py
```

Скрипт объединяет датасеты (`reviews.csv`, `Dataset.csv`, `extra_sentiment.csv`, `feedback.csv` — более 700 уникальных текстов), проводит 10-фолдовую кросс-валидацию по метрике F1-macro ($\approx 0.84$) и сохраняет веса в каталог `models/`.

### 3. Запуск веб-приложения

Запустите сервер Streamlit:

```powershell
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
```

После старта веб-интерфейс автоматически откроется в браузере по адресу:  
`http://localhost:8501`

## Пайплайн машинного обучения

### 1. Предобработка текстов (`src/preprocess.py`)
Функция `clean(text)` выполняет пошаговую нормализацию:
- **Обработка интернет-сленга:** замена жаргонизмов (*«кринж»*, *«оверпрайс»*, *«шляпа»*, *«скам»*) на их литературные смысловые аналоги из словаря `data/slang_dict.csv`.
- **Очистка от шума:** удаление ссылок, email-адресов, HTML-разметки и небуквенных символов.
- **Лемматизация:** приведение слов к начальной форме с помощью `pymorphy3`.
- **Склейка отрицаний:** объединение частиц `не`, `нет`, `ни` со следующим за ними словом (`не_понравиться`, `не_советовать`). Это предотвращает потерю инверсии смысла при разбиении на отдельные слова.

### 2. Векторизация (`TfidfVectorizer`)
- Диапазон n-грамм: `(1, 2)` (учет отдельных слов и биграмм);
- Логарифмическое затухание частот: `sublinear_tf=True` ($1 + \log(\text{tf})$), что уменьшает вес аномально частых токенов;
- Максимальный размер словаря: 5000 наиболее информативных признаков.

### 3. Классификатор (`ComplementNB`)
- Выбран метод **Complement Naive Bayes** (`alpha=0.5`).
- В отличие от стандартного `MultinomialNB`, ComplementNB рассчитывает вероятности относительно дополнения каждого класса, что делает его значительно более устойчивым на несбалансированных корпусах текстов.
- Среднее качество модели на 10-фолдовой кросс-валидации составляет **F1-macro $\approx 0.84$**.

## Форматы данных

- `data/reviews.csv` и `data/Dataset.csv` — основные размеченные выборки со столбцами `text` и `label`.
- `data/extra_sentiment.csv` — набор типовых коротких фраз (отрицания, жалобы на брак, рекомендации).
- `data/slang_dict.csv` — таблица сленга со столбцами `slang`, `нормализация`, `тип`.
- `data/feedback.csv` — журнал исправлений из веб-интерфейса (`text`, `label`, `model_prediction`).

## Часто встречающиеся проблемы и решения

### Ошибка: `streamlit : The term 'streamlit' is not recognized...`
Пакет не установлен глобально, либо директория со скриптами Python отсутствует в переменной PATH.  
Запускайте Streamlit напрямую через исполняемый файл из локального окружения:
```powershell
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
```

### Ошибка: `FileNotFoundError: models/nb_model.pkl`
Веса модели еще не скомпилированы. Запустите первичное обучение:
```powershell
.\.venv\Scripts\python.exe src/train.py
```
Либо воспользуйтесь кнопкой дообучения в боковом меню веб-интерфейса.
