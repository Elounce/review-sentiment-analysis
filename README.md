# 📊 Sentiment Analysis of Reviews (Анализ тональности отзывов)

Интерактивная система для автоматической классификации тональности русскоязычных отзывов на базе машинного обучения (**Scikit-Learn**) и веб-интерфейса (**Streamlit**). Проект поддерживает пакетную обработку данных, наглядную визуализацию и механизм непрерывного улучшения модели на основе пользовательской обратной связи (**Active Learning / Feedback Loop**).

## 🚀 Основные возможности

- **Классификация на 3 категории:**
  - 🟢 **Позитив** (`positive`)
  - 🟡 **Нейтрал** (`neutral`)
  - 🔴 **Негатив** (`negative`)
- **Гибкий ввод данных:**
  - Ручной ввод одного или нескольких отзывов (построчно).
  - Пакетная загрузка файлов через интерфейс (`.csv` или `.txt`).
- **Интерактивный дашборд:**
  - Метрики распределения отзывов по категориям.
  - Круговые (Pie) и столбчатые (Bar) диаграммы в реальном времени.
  - Карточки отзывов с расчётом процента уверенности модели (`confidence`).
- **Механизм обратной связи (Active Learning):**
  - Возможность прямо в интерфейсе исправить ошибку модели («Модель ошиблась?»).
  - Исправления сохраняются в `data/feedback.csv` и автоматически учитываются при следующем переобучении.
- **Экспорт отчётов:**
  - Выгрузка результатов классификации в файл CSV (`results.csv`) в кодировке `utf-8-sig`.

## 🛠 Стек технологий

- **Библиотеки NLP & ML:**
  - `scikit-learn` — векторизация текстов (`TfidfVectorizer`), классификаторы (`ComplementNB`, `LogisticRegression`), метрики качества и кросс-валидация.

  - `wordcloud` — визуализация частотных слов (облака тегов).

## ⚙️ Установка и запуск

### 1. Подготовка окружения

Рекомендуется использовать изолированное виртуальное окружение:

```powershell
# Создание виртуального окружения (Python 3.12)
python -m venv .venv

# Активация окружения (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# Установка всех зависимостей
pip install -r requirements.txt
```

> [!NOTE]
> Если в вашей системе установлен менеджер пакетов `uv`, можно выполнить установку быстрее:
> ```powershell
> uv venv .venv --python 3.12
> uv pip install -r requirements.txt --python .venv
> ```

---

### 2. Обучение / переобучение модели

Перед первым запуском приложения (или после накопления новых данных в `data/feedback.csv`) обучите модель:

```powershell
# Запуск из активированного окружения:
python src/train.py

# Либо напрямую через python из .venv:
.\.venv\Scripts\python.exe src/train.py
```

Скрипт выполнит:
1. Загрузку `data/reviews.csv` и объединение с `data/feedback.csv` (с дедупликацией).
2. Очистку и векторизацию текстов.
3. 10-фолдовую кросс-валидацию с расчётом `F1-macro`.
4. Обучение финальной модели на всем объеме данных и сохранение весов в `models/nb_model.pkl` и `models/vectorizer.pkl`.

---

### 3. Запуск веб-интерфейса

Запустите Streamlit-приложение:

```powershell

.\.venv\Scripts\streamlit.exe run app/streamlit_app.py

# Вариант 2 (из активированного окружения):
streamlit run app/streamlit_app.py
```

После старта в браузере автоматически откроется страница по адресу:  
👉 **`http://localhost:8501`**

## 🧠 Пайплайн машинного обучения

### 1. Предобработка текстов (`src/preprocess.py`)
Функция `clean(text)` реализует следующие шаги:
- Приведение текста к нижнему регистру.
- Удаление URL-адресов, email, HTML-тегов и небуквенных символов (оставляются кириллица, латиница и пробелы).
- **Лемматизация** каждого слова с использованием `pymorphy3` (приведение к нормальной форме, например: *«отличные» $\to$ «отличный»*).
- **Специфическая обработка отрицаний:** частица `не` склеивается с идущим следом словом через знак подчеркивания (например, *«не понравился» $\to$ «не_понравиться»*). Это позволяет векторизатору учитывать инверсию смысла, а не терять контекст.

### 2. Нормализация сленга (`data/slang_dict.csv` / `models/model.py`)
Словарь содержит типичные конструкции молодежного и интернет-жаргона с их классификацией:
- `phrase` — устойчивые фразы (заменяются первыми по убыванию длины).
- `polarity` — слова с эмоциональной окраской (*«кринж»*, *«шляпа»*, *«топ»*, *«скам»*).
- `intensifier` — усилители (*«жесть»* заменяется на *«очень»*).

### 3. Векторизация (`TfidfVectorizer`)
- Параметры:
  - `ngram_range=(1, 2)` — извлечение униграмм и биграмм (включая склеенные отрицания вроде `не_работать`).
  - `max_features=5000` — ограничение словаря наиболее информативными токенами.
  - `min_df=1`.

### 4. Классификатор (`ComplementNB`)
- В качестве основного алгоритма выбран **Complement Naive Bayes** (`ComplementNB(alpha=2.0)`).
- **Почему именно он:** в отличие от стандартного `MultinomialNB`, данный метод специально разработан для несбалансированных текстовых наборов данных и показывает высокую стабильность на коротких отзывах.
- Оценка качества проводится по метрике **Macro F1-Score** через 10-Fold Cross-Validation.

## 📊 Форматы входных и выходных данных

### 1. Файл обучающих данных (`data/reviews.csv`)
CSV-файл в кодировке UTF-8 со следующими столбцами:
| Столбец | Тип | Описание | Пример |
|---|---|---|---|
| `text` | string | Текст отзыва | *"Качество отличное, пользуюсь уже месяц."* |
| `label` | string | Метка класса (`positive`, `neutral`, `negative`) | `positive` |

### 2. Файл пользовательской обратной связи (`data/feedback.csv`)
Формируется автоматически при нажатии кнопки исправления в UI:
| Столбец | Описание |
|---|---|
| `text` | Исходный текст отзыва |
| `label` | Скорректированный пользователем правильный класс |
| `model_prediction` | Класс, который изначально предсказала модель |

### 3. Файлы для пакетной загрузки в Streamlit
- **CSV:** файл с заголовками, где первый столбец содержит тексты отзывов.
- **TXT:** текстовый файл, в котором каждый отзыв записан с новой строки.

## ❓ Часто встречающиеся проблемы и решения

### 1. `streamlit : The term 'streamlit' is not recognized...`
**Причина:** Пакет не установлен глобально, либо директория со скриптами Python не добавлена в системный `PATH`.  
**Решение:** Запускайте Streamlit через абсолютный/относительный путь из виртуального окружения:
```powershell
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
```

### 2. Ошибка `FileNotFoundError: models/nb_model.pkl` при открытии сайта
**Причина:** Модель ещё не была скомпилирована и сохранена.  
**Решение:** Обучите модель перед запуском веб-приложения:
```powershell
.\.venv\Scripts\python.exe src/train.py
```

### 3. Ошибка выполнения скриптов в PowerShell (`ExecutionPolicy`)
**Причина:** Политика безопасности Windows блокирует выполнение сценария `Activate.ps1`.  
**Решение:** Разрешите выполнение скриптов для текущего сеанса PowerShell:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 4. Некорректное отображение русских букв в сохранённом CSV в Excel
**Решение:** Результаты в веб-интерфейсе выгружаются в формате `utf-8-sig` (с маркером BOM), что обеспечивает автоматическое корректное распознавание кириллицы в Microsoft Excel.
