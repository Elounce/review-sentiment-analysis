# 📊 Разработка веб-сайта для классификации эмоциональной окраски отзывов на основе наивного байесовского классификатора

**Тема выпускной / исследовательской работы:** *«Разработка веб-сайта для классификации эмоциональной окраски отзывов на основе наивного байесовского классификатора»*

Интерактивная система для автоматической классификации тональности русскоязычных отзывов на базе наивного байесовского классификатора (**Scikit-Learn ComplementNB**) и веб-интерфейса (**Streamlit**). Проект поддерживает пакетную обработку данных, объяснение решений модели (Explainability / XAI), наглядную визуализацию и механизм непрерывного улучшения модели на основе пользовательской обратной связи (**Active Learning / Feedback Loop**).

## 🚀 Основные возможности

- **Классификация на 3 категории:**
  - 🟢 **Позитив** (`positive`)
  - 🟡 **Нейтрал** (`neutral`)
  - 🔴 **Негатив** (`negative`)
- **Объяснение предсказаний (Explainable AI):**
  - Подсветка ключевых слов-триггеров для каждого отзыва, которые сильнее всего склонили модель к данному решению.
- **Гибкий ввод данных:**
  - Ручной ввод одного или нескольких отзывов (построчно).
  - Пакетная загрузка файлов через интерфейс (`.csv` или `.txt`).
- **Интерактивный дашборд:**
  - Метрики распределения отзывов по категориям.
  - Круговые (Pie) и столбчатые (Bar) диаграммы в реальном времени.
  - Карточки отзывов с расчётом процента уверенности модели (`confidence`).
- **Механизм обратной связи (Active Learning):**
  - Возможность прямо в интерфейсе исправить ошибку модели («Модель ошиблась?»).
  - Исправления сохраняются в `data/feedback.csv`.
  - **Кнопка переобучения прямо в веб-интерфейсе** (в боковом меню), моментально обновляющая модель в памяти.
- **Экспорт отчётов:**
  - Выгрузка результатов классификации в файл CSV (`sentiment_results.csv`) в кодировке `utf-8-sig` (корректно открывается в Microsoft Excel).

## 🛠 Стек технологий

- **Язык программирования:** Python 3.10+ (рекомендуется Python 3.12)
- **Библиотеки NLP & ML:**
  - `scikit-learn` — векторизация текстов (`TfidfVectorizer`), классификатор `ComplementNB`, метрики качества и кросс-валидация.
  - `pymorphy3` — морфологический анализ и лемматизация русской речи.
  - `pandas` — работа с табличными данными и датасетами.
  - `joblib` — сериализация обученных моделей и векторизаторов.
- **Интерфейс и визуализация:**
  - `streamlit` — реактивный веб-фреймворк для дашборда.
  - `matplotlib` — построение графиков и диаграмм.
  - `wordcloud` — визуализация частотных слов (облака тегов).

## ⚙️ Установка и запуск

### 1. Подготовка окружения

Рекомендуется использовать изолированное виртуальное окружение:

```powershell
# Создание виртуального окружения (Python 3.12)
python -m venv .venv

# Активация окружения (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# Установка всех зависимостей
pip install -r requirements.txt
```

---

### 2. Обучение / переобучение модели

Для обучения модели на объединенном корпусе данных выполните:

```powershell
# Запуск напрямую через python из .venv:
.\.venv\Scripts\python.exe src/train.py

# Или из активированного окружения:
python src/train.py
```

Скрипт объединяет `reviews.csv`, `Dataset.csv`, `extra_sentiment.csv` и `feedback.csv` (более 700 уникальных отзывов), проводит 10-фолдовую кросс-валидацию (F1 $\approx$ 0.84) и сохраняет веса в `models/`.

---

### 3. Запуск веб-интерфейса

Запустите Streamlit-приложение:

```powershell
# Вариант 1 (прямой запуск без активации):
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py

# Вариант 2 (через модуль python):
.\.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py
```

После старта в браузере автоматически откроется страница:  
👉 **`http://localhost:8501`**

## 🧠 Пайплайн машинного обучения

### 1. Предобработка текстов (`src/preprocess.py`)
Функция `clean(text)` реализует следующие шаги:
- **Нормализация сленга (`data/slang_dict.csv`):** преобразование сленговых выражений (*«кринж»*, *«шляпа»*, *«оверпрайс»*, *«скам»*) в понятные по эмоциональной полярности эквиваленты.
- Удаление URL-адресов, email, HTML-тегов и небуквенных символов.
- **Лемматизация** через `pymorphy3` (приведение слов к нормальной словарной форме).
- **Специфическая обработка отрицаний:** частицы `не`, `нет`, `ни` склеиваются со следующим словом через знак подчеркивания (например, *«не понравился» $\to$ «не_понравиться»*). Это позволяет векторизатору сохранять инверсию смысла.

### 2. Векторизация (`TfidfVectorizer`)
- `ngram_range=(1, 2)` — учитываются отдельные слова и устойчивые словосочетания.
- `sublinear_tf=True` — логарифмическое масштабирование частот терминов ($1 + \log(\text{tf})$), предотвращающее доминирование часто повторяющихся слов.
- `max_features=5000`.

### 3. Классификатор (`ComplementNB`)
- Выбран **Complement Naive Bayes** (`ComplementNB(alpha=0.5)`).
- В отличие от стандартного `MultinomialNB`, данный классификатор оптимизирован для работы с текстовыми выборками при возможном дисбалансе классов.
- Достигает среднего **Macro F1-Score $\approx 0.84$** на кросс-валидации.

## 📊 Форматы данных

- **`data/reviews.csv`** и **`data/Dataset.csv`**: датасеты с колонками `text` и `label`.
- **`data/extra_sentiment.csv`**: корпус типовых конструкций (отрицания, брак, рекомендации).
- **`data/slang_dict.csv`**: словарь интернет-жаргона (`slang`, `нормализация`, `тип`).
- **`data/feedback.csv`**: журнал пользовательских правок из веб-интерфейса (`text`, `label`, `model_prediction`).

## ❓ Часто встречающиеся проблемы и решения

### 1. `streamlit : The term 'streamlit' is not recognized...`
**Решение:** Запускайте Streamlit напрямую через исполняемый файл из `.venv`:
```powershell
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
```

### 2. Ошибка отсутствия весов модели
**Решение:** Запустите обучение перед стартом:
```powershell
.\.venv\Scripts\python.exe src/train.py
```
Либо воспользуйтесь кнопкой «Переобучить модель сейчас» в боковом меню веб-интерфейса.
